# Code of Conduct

This project strives to maintain a friendly, constructive, and productive environment.

- **Respect**: Treat everyone with courtesy. Discuss code and technical approaches, not personalities.
- **Focus**: Keep discussions and issue tickets focused on the software and its usability.
- **Zero tolerance**: Harassment, insults, or trolling will result in immediate issue closure and bans.

To report unacceptable behavior, reach out directly to `@ivanchikbyte` on Telegram or via email at `ivanchikbyte@gmail.com`.
